# 小红书链接生成器

小红书广告投放工具集，支持投放链接生成与广告计划命名。自动输出 **DP 链接（Deeplink）**、**Universal Link**、**兜底链接**、**监测链接** 以及 **广告计划命名**。

## 在线地址

🔗 [https://supermancage.github.io/xhs-link-generator3/](https://supermancage.github.io/xhs-link-generator3/)

> 说明：该地址现已整合为「小红书投放工具箱」入口壳页面（关键词分类 / 链接生成 / 返货监控），

## 功能说明

### oCityID 城市参数（新增）

部分投放链接支持追加 `oCityID` 城市参数。当投放链接的 `activitycode` 属于以下白名单时生效：

- `7d11cd76-3678-4d3f-a001-c2431031fc7c`
- `b6816e18-1a7d-4c70-b387-ff8fa0d3327e`
- `62732a0d-ee87-4f63-9af5-824fb7a0513b`
- `abe982cd-9050-47d6-ac1c-ffd4b008a10d`

规则：

1. **单个生成**：在「oCityID 城市」框输入/选择城市（支持 9,633 个地级/县级城市及海外目的地搜索），生成时自动在投放链接末尾追加 `&oCityID=城市ID`（如 `&oCityID=1102`），DP / UL / 兜底链接同步携带
2. **批量生成**：复用「酒店城市」列，填城市名即可，命中白名单时自动查表转 ID 追加；城市名匹配不成功的行**不报错跳过**，忽略城市按原逻辑照常生成，并在结果尾列「生成结果」标注原因（见下方状态表）
3. 命中白名单但未提供城市 → 提示「城市为选填」，按原逻辑生成；提供了城市但 activitycode 不在白名单 → 提示「已忽略城市」，按原逻辑生成（均不阻断，可继续）
4. 链接已含 `oCityID` 时不重复追加（幂等）
5. 城市数据维护在 `js/citydata.js`，来源为城市列表 list.xlsx（艺龙城市 ID 全量表，含地级主 ID / 县级扩展 ID / 海外目的地）；`CITY_RAW` 段由 `qa-verify/build_citydata.py` 重建（勿手改），`activityCodes` 白名单为手工维护段

批量输出（CSV / Excel / 预览表格）的**尾列「生成结果」**会逐行标注 oCityID 处理状态，共 5 种：

| 状态 | 含义 |
|------|------|
| 活动activity不支持城市添加 | activitycode 不在白名单（或链接中缺失），城市参数被忽略 |
| 活动activity支持城市添加，未填城市 | 命中白名单但「酒店城市」为空（城市选填，不追加） |
| 活动activity支持城市添加，城市匹配成功 | 已自动追加 `&oCityID=城市ID` |
| 活动activity支持城市添加，城市匹配不成功 | 城市名在对照表中未找到，忽略城市按原逻辑生成 |
| 投放链接已含 oCityID，未重复追加 | 幂等保护，检测到已有该参数则跳过 |

### 单个生成
1. 填写 **投放链接**、**Refid**（必填）和 **笔记 ID**（选填）
2. 填写广告计划命名字段（素材类型、业务线、内容类型、酒店城市/目的地、投放活动、定向等）
3. 点击「生成链接」
4. 一键生成 **广告计划命名** 和四种投放链接（DP链接、Universal Link、兜底链接、监测链接）
5. 可逐条复制，酒店名称仅「非标种草」时必填

### 批量生成
1. 下载 **Excel 模板**（页面上「下载 Excel 模板」按钮），按格式填写 `笔记ID,投放链接,refid,素材类型,业务线,内容类型,酒店城市,酒店名称,投放活动,定向`
2. 兼容 9 列格式（可省略最后的「定向」列，定向留空）与旧格式（仅 3 列：`笔记ID,投放链接,refid`），3 列旧格式命名字段留空
3. 上传文件（支持 `.xlsx` / `.csv` / `.txt`；`.csv` / `.txt` 也可用空格分隔 `笔记ID 投放链接 refid`）
4. 点击「批量生成」，支持逐行容错（格式 / 必填校验失败的行跳过并提示，正常行照常生成）
5. 批量输出含广告计划命名、四种链接及「生成结果」状态列（5 种状态见上）的完整表格，预览区域同步展示前 10 行
6. 可复制全部结果，或下载为 **CSV / Excel** 文件

## 技术栈

- **HTML / CSS / JavaScript**（原生实现，无构建步骤）
- 依赖两个第三方 CDN 库，**使用需联网**：
  - **SheetJS**（`xlsx-0.20.3`，来源：<https://cdn.sheetjs.com>）—— Excel 读写支持
  - **qrcode-generator**（`1.4.4`，来源：<https://cdn.jsdelivr.net>）—— 二维码生成
- 部署于 GitHub Pages，开箱即用
