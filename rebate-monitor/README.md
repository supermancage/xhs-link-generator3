# 返货余额监控仪表盘

同程旅行投放返货余额监控工具：展示各投放账户的「普通返货余额」可支撑天数，并给出账户间返货余额的转入/转出调拨建议。

## 功能

- 全部账户 / 需转入 / 可转出 / 闲置余额 四个视图
- 可支撑天数分布图、资金调拨概览（转入/转出 Top 10）
- 支持手动导入日结报表（.xlsx / .xls）并重新计算
- 支持导出 CSV（返货余额调拨建议）

## 数据来源与更新

数据文件为 `account_data.json`，由脚本 `update_data.py` 从日结 Excel 报表生成：

```bash
python3 update_data.py <日结报表.xlsx> [--days 10]
```

参数说明：

- `<日结报表.xlsx>`：必填，日结报表 Excel 文件（含「账户ID」「账户名称」「账户消耗-普通返货」「普通返货余额」「账户总消耗」「日期」等列）
- `--days 10`：可选，目标可支撑天数（默认 10，用于计算转入/转出建议）

生成 `account_data.json` 后刷新页面即可看到最新数据；也可以在页面右上角「📂 加载新报表」手动导入，无需重新生成文件。

## 页面使用

纯静态页面，直接以任意静态服务器打开即可（无需构建）：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```
